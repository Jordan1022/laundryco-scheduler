# Brand Assets

Logo artwork for `<Brandmark variant="..." />`.

| File in this folder | `variant` prop |
|---|---|
| `wordmark-leaguecity-below-script.png` | `wordmark-leaguecity` |
| `mascot-washer-character.png` | `mascot` |

See `BRAND.md` §4 for usage rules (clear space, minimum size, recolor/stretch restrictions).

When more variants ship (red badge, navy-fill wordmark, etc.), drop them here and add a matching entry to `variantSources` in `components/ui/Brandmark.tsx`.

With no `variant` specified, `<Brandmark />` falls back to the LC rubber stamp.
